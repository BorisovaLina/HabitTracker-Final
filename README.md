HabitTracker



Мобильное приложение для формирования полезных привычек, отслеживания прогресса и достижения целей.  

Разработано как учебный проект.



Основные возможности



\- Создание и управление привычками

&nbsp; Укажите название, описание, частоту (ежедневно, будни, выходные, конкретные дни), цель (например, «2 л воды») и сложность.

\- Интерактивный календарь  

&nbsp; Визуализация выполнения привычек с поддержкой переключения между неделями и месяцами. Неделя начинается с понедельника.

\- Статистика 

&nbsp; Просмотр количества привычек, выполненных сегодня, средней сложности и общей активности.

\- Достижения 

&nbsp; Разблокируйте бейджи за создание 1, 5, 10, 25, 50, 100 привычек или выполнение всех привычек за день.

\- Темная/светлая тема 

&nbsp; Автоматическое или ручное переключение оформления.

\- Авторизация  

&nbsp; Защита данных с помощью логина и пароля (локальное хранение).

\- Резервное копирование

&nbsp; Экспорт базы данных SQfLite для сохранения прогресса.



Технологии



\- Язык: Dart

\- Фреймворк: Flutter (v3.38.1)

\- Архитектура: Provider (State Management)

\- База данных: SQLite через `sqflite`

\- Локализация: Русский язык

\- UI/UX: кастомная цветовая схема



Дизайн



\- Цветовая схема:

&nbsp; - Светлая тема: белый фон (`#FFFFFF`), акцентный красный (`#E96B7D`)

&nbsp; - Тёмная тема: тёмный фон, зелёные акценты

\- Шрифт: Inter (sans-serif)

\- Доступность: Контрастные цвета, поддержка темной темы
